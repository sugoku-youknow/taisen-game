# ゴム弾き陣取りバトル (対戦ゲーム オンライン版)

元のPPTX企画(ゴムを使って玉を相手陣地に発射し合う2〜4人対戦ゲーム)を、ブラウザだけで
オンライン対戦できるようにしたWebゲームです。**サーバーは一切不要**で、GitHub Pagesの
ような静的ホスティングだけで動きます。

## 仕組み

- **物理演算**: [Matter.js](https://brm.io/matter-js/) で、ゴムを引っ張って玉を発射する
  動きを再現しています。
- **通信**: [Trystero](https://github.com/dmotz/trystero) というライブラリで、ブラウザ同士が
  サーバーを介さず直接つながります(WebRTC)。「部屋を作った人」がそのままホストになり、
  ホストの端末だけが物理演算の正解を計算し、他の参加者(ゲスト)にその結果を配信します。
- **盤面**: 部屋に集まった人数によって自動で変わります。
  - 2人 → 長方形(上下2分割)
  - 3人 → 六角形(3分割)
  - 4人 → 八角形(4分割)
  - 各自の陣地の中心に近い部分だけを通って、玉が隣の陣地へ抜けられます。
- **勝敗**: 自分の陣地の玉を先に0個にした人の勝ちです(他の人が撃ち込んできた玉が自分の陣地に
  増えることもあるので、油断できません)。

## 遊び方

1. 誰か1人が「部屋を作る」を押す → 5桁の部屋コードが表示される
2. 他の人(1〜3人)がそのコードを「部屋に参加する」に入力
3. 部屋を作った人(ホスト)が人数を確認して「ゲームを開始する」を押す
4. 自分の陣地(色が濃い方)の玉をドラッグして引っ張り、指を離すと発射
5. どこかの陣地が0個になったら終了

## ローカルで試す

```bash
npx serve .
# または
python3 -m http.server 8000
```

ブラウザで開いたローカルアドレスに、別のブラウザ(または別の端末)からも同じアドレスで
アクセスすれば、同じ部屋コードで対戦できます。

## GitHub Pagesへの公開手順

1. このフォルダの中身をリポジトリのルート(または `docs/` フォルダ)にそのままpush
2. GitHubのリポジトリ → **Settings → Pages** で公開元のブランチ/フォルダを指定
3. 数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます
4. あとはそのURLを対戦相手に送るだけで、みんな同じ部屋コードを使って対戦できます

ビルド work は一切不要です。`index.html` を静的配信するだけで動きます。

## ファイル構成

```
index.html        画面のHTML(ロビー/待機/対戦/終了の4画面)
style.css         見た目
js/board.js       盤面の形・陣地・初期配置(2/3/4人分)
js/physics.js     Matter.jsのラッパー(壁・玉・発射)
js/network.js     Trystero(P2P通信)のラッパー
js/game.js        ロビー→対戦→終了の状態管理、ホスト権威型の同期
js/main.js        画面切り替え・キャンバス描画・ドラッグ操作
```

## 既知の制限・今後の改善候補

- **途中参加は不可**: ホストがゲームを開始した後に部屋に入っても、その回の対戦には参加できません
  (次の対戦から遊べます)。
- **ホストが抜けると対戦が止まります**: ホストの物理演算が唯一の正解のため、ホストが離脱すると
  同期が止まります。再戦時は誰かが新しく部屋を作り直してください。
- **5人以上には非対応**: 現状は2〜4人までです。5人目以降は待機画面に残ったまま対戦には
  加われません。
- **接続について**: TrysteroはデフォルトでNostrという分散ネットワークを経由して最初の接続先を
  見つけます(通信内容自体はP2Pで直接やり取りされ、ここを経由しません)。まれに大学・会社の
  ネットワークなど制限の強い回線では接続できないことがあります。その場合は
  `js/network.js` の `TRYSTERO_CDN_URL` を別の戦略(`trystero/mqtt` など)に変更すると
  改善することがあります。
- **不正対策なし**: 身内で遊ぶ前提のミニゲームのため、送られてきた入力の妥当性チェックは
  最低限(自分の陣地の玉かどうか)のみです。
